Tree & Graph Traversal Templates

The handful of skeletons that solve most tree (and many graph) problems. Memorise these; vary only the per-node work.

Node definitions

class TreeNode { int val; TreeNode left, right; }
// Graph: Map<Integer, List<Integer>> adj;  or  int[][] grid;

DFS — recursive (the default)

void dfs(TreeNode node) {
    if (node == null) return;        // base case
    // preorder work here
    dfs(node.left);
    // inorder work here  (BST → sorted order)
    dfs(node.right);
    // postorder work here (children done → bottom-up aggregates)
}

Choose the slot by what you need: preorder for top-down (pass info down via parameters), postorder for bottom-up (combine children's returns — heights, sums, "is balanced"). Inorder of a BST yields sorted values.

Postorder aggregation (the workhorse for "compute a property")

int height(TreeNode node) {
    if (node == null) return 0;
    int l = height(node.left), r = height(node.right);
    return 1 + Math.max(l, r);       // combine children → my answer
}

Most "max path", "diameter", "is balanced", "is valid BST" problems are postorder: return an aggregate, and keep a separate field/array for the global best.

BFS — level order (queue)

List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>();
    q.offer(root);
    while (!q.isEmpty()) {
        int n = q.size();             // freeze this level's width
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            TreeNode cur = q.poll();
            level.add(cur.val);
            if (cur.left  != null) q.offer(cur.left);
            if (cur.right != null) q.offer(cur.right);
        }
        res.add(level);
    }
    return res;
}

The int n = q.size() snapshot is what separates levels. Use BFS for shortest-path-in-unweighted, level-by-level work, and "right side view" type problems.

Iterative DFS (when recursion depth is a risk)

Deque<TreeNode> st = new ArrayDeque<>();
st.push(root);
while (!st.isEmpty()) {
    TreeNode cur = st.pop();
    if (cur == null) continue;
    // visit cur
    st.push(cur.right);   // push right first so left is processed first
    st.push(cur.left);
}

Graph DFS / BFS (adjacency list)

// DFS with visited set
void dfs(int u, Map<Integer,List<Integer>> adj, Set<Integer> seen) {
    if (!seen.add(u)) return;        // add returns false if already present
    for (int v : adj.getOrDefault(u, List.of())) dfs(v, adj, seen);
}

// BFS shortest path (unweighted)
int bfs(int src, int dst, Map<Integer,List<Integer>> adj) {
    Queue<Integer> q = new LinkedList<>(); q.offer(src);
    Set<Integer> seen = new HashSet<>(); seen.add(src);
    int dist = 0;
    while (!q.isEmpty()) {
        int n = q.size();
        for (int i = 0; i < n; i++) {
            int u = q.poll();
            if (u == dst) return dist;
            for (int v : adj.getOrDefault(u, List.of()))
                if (seen.add(v)) q.offer(v);
        }
        dist++;
    }
    return -1;
}

Grid traversal (implicit graph)

int[][] DIRS = {{1,0},{-1,0},{0,1},{0,-1}};
void dfs(char[][] g, int r, int c) {
    if (r < 0 || c < 0 || r >= g.length || c >= g[0].length || g[r][c] != '1') return;
    g[r][c] = '0';                   // mark visited in place
    for (int[] d : DIRS) dfs(g, r + d[0], c + d[1]);
}
