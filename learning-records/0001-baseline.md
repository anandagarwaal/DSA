# Baseline established: rusty senior engineer, Google/Meta target

The user is a senior engineer (Flipkart) targeting L6/L7 SWE at Google and Meta,
with a 3–6 month runway. Self-rates as **rusty** — was once competent at DSA but
has a long practice gap. Prefers a mix style: short concept, then immediate drill.

**Implications for teaching:**
- Don't start from absolute zero (they know what a HashMap is), but *do* re-prove
  fundamentals like complexity tradeoffs rather than assume recall.
- The Google bar means every lesson must train the *why* (correctness + complexity
  justification); the Meta bar means it must also train speed and clean code.
- Build storage strength via spacing/interleaving — there's runway, so optimise
  for retention over cramming. Start the pattern curriculum at hashing (lesson 0001).
