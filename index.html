How this course works

Built on The Math Academy Way. Everything runs in these pages; chat is optional.

  1. Review first. Each day, open Review before anything new. Topics come back on an expanding schedule (1 → 3 → 7 → 14 → 30 … days), just before you would forget them. Questions are mixed across topics and closed-book.
  2. Read first, then answer. A lesson is a series of small steps, and every step is open from the moment you arrive: a short explanation with a worked example and a picture, then questions on it while it is fresh. 3 correct marks a step passed. Nothing is locked — a miss tells you which paragraph to reread, it does not bar the next one. A closed-book quiz ends each topic, and a cumulative section quiz ends each section.
  3. Placement is an offer, not a toll. Each lesson starts with two folded-away options you can ignore: place out of the topic by passing its quiz cold, or warm up on the prerequisites it uses. The normal path is to read the lesson.
  4. Suggested order, not a gate. The dashboard proposes what to learn next — topics whose prerequisites are already mastered come first — but every topic below is open today if you want it.
  5. Then go and solve. Each topic ends with worked practice problems (with solutions) and a list of suggested problems on LeetCode and CSES with no solutions attached. Reading a pattern is not owning it; volume is.
  6. Intuition over procedure. Many questions ask for the picture, the proof, a counterexample, or a problem you haven't seen. For written answers you commit first, then grade yourself against a checklist. A step missing from your argument counts as a miss.

Progress lives in progress.json, shared with Claude sessions. Run python3 tools/serve.py so the pages can save it.
