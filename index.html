How this course works

Built on The Math Academy Way. Everything runs in these pages; chat is optional.

  1. Review first. Each day, open Review before anything new. Topics come back on an expanding schedule (1 → 3 → 7 → 14 → 30 … days), just before you would forget them. Questions are mixed across topics and closed-book.
  2. Placement, not assumption. Every unverified topic starts with an optional placement quiz. Pass it and you skip the lesson. Prerequisites are tested too: each lesson opens with a warm-up on the topics it builds on.
  3. Frontier only. Learn a topic once everything it builds on is mastered. The dashboard above lists what is ready.
  4. Bit by bit. A lesson is a series of small steps. Each step is a short explanation with a worked example and a picture, then questions: 3 correct to unlock the next step, and a second miss sends you back to the prerequisites. A closed-book quiz ends each topic, and a cumulative section quiz ends each section.
  5. Intuition over procedure. Many questions ask for the picture, the proof, a counterexample, or a problem you haven't seen. For written answers you commit first, then grade yourself against a checklist. A step missing from your argument counts as a miss.

Progress lives in progress.json, shared with Claude sessions. Run python3 tools/serve.py so the pages can save it.
