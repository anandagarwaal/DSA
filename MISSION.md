# Mission: DSA for L6/L7 Software Engineer Interviews

## Why
Land an L6/L7 (Staff-level) Software Engineer offer at Google and/or Meta. The
coding rounds gate the entire loop — being rusty on DSA is the single biggest
risk to an otherwise strong senior candidacy. The goal is to convert years of
real-world engineering experience into fluent, confident, *communicated*
problem-solving on medium–hard problems under a 35–45 minute clock.

## Success looks like
- Solve a Meta-style pair of LeetCode mediums in ~35 minutes, optimal solution, clean Java.
- Recognise the right pattern within the first 2–3 minutes of reading a problem.
- State time/space complexity and justify *why* the approach is correct (the Google bar).
- Handle edge cases and dry-run code before claiming it works — without prompting.
- Think out loud fluently: narrate tradeoffs, not just type silently.

## Constraints
- **Timeline:** 3–6 months. Pace for retention, not cramming.
- **Baseline:** Rusty — was once competent, needs fundamentals rebuilt before hards.
- **Language:** Java.
- **Style:** Mix — short concept lesson, then immediate drill with tight feedback loops.
- Working full-time (Flipkart); sessions must be short and self-contained.

## Out of scope (for now)
- Competitive-programming exotica (heavy number theory, advanced geometry, suffix automata).
- System design (separate track — this workspace is DSA only).
- Language trivia / Java internals beyond what coding rounds need.
