Lesson 0017 · Linked Lists — Reps

More Linked List Problems

Four reps: merge, reorder (composing idioms), group reversal, and a deep-copy with random pointers.

From Lesson 0016 you have reversal, fast/slow, and the dummy head. These reps make you compose them — the L6/L7 list questions are rarely one idiom alone. Narrate which idiom each phase uses as you write it.

Drill 1 — merge with dummy LeetCode 21 · Merge Two Sorted Lists

Merge two sorted lists into one sorted list by splicing nodes.

Hint

Dummy head + a tail pointer. Repeatedly attach the smaller head and advance. At the end, attach whichever list remains.

Solution (Java) 
public ListNode mergeTwoLists(ListNode a, ListNode b) {
    ListNode dummy = new ListNode(0), tail = dummy;
    while (a != null && b != null) {
        if (a.val <= b.val) { tail.next = a; a = a.next; }
        else                { tail.next = b; b = b.next; }
        tail = tail.next;
    }
    tail.next = (a != null) ? a : b;   // attach the remainder
    return dummy.next;
}

Time O(m+n) · Space O(1). Insight: splicing existing nodes (not allocating new ones) keeps it O(1) extra space — and the trailing attach avoids a final loop.

Drill 2 — compose three idioms LeetCode 143 · Reorder List

Reorder L0→L1→…→Ln into L0→Ln→L1→Ln−1→… in place.

Hint

Three phases: (1) fast/slow to find the middle, (2) reverse the second half, (3) merge the two halves alternately. Each phase is an idiom you already own.

Solution (Java) 
public void reorderList(ListNode head) {
    if (head == null || head.next == null) return;
    ListNode slow = head, fast = head;                    // 1. find middle
    while (fast.next != null && fast.next.next != null) {
        slow = slow.next; fast = fast.next.next;
    }
    ListNode prev = null, cur = slow.next;                 // 2. reverse 2nd half
    slow.next = null;
    while (cur != null) { ListNode n = cur.next; cur.next = prev; prev = cur; cur = n; }
    ListNode first = head, second = prev;                  // 3. weave
    while (second != null) {
        ListNode f = first.next, s = second.next;
        first.next = second; second.next = f;
        first = f; second = s;
    }
}

Time O(n) · Space O(1). Insight: decomposing into three known idioms is the whole skill — recognising a "hard" as a composition is exactly what interviewers reward.

Drill 3 — reverse in groups LeetCode 25 · Reverse Nodes in k-Group

Reverse the list k nodes at a time; leftover tail (< k) stays as-is. A genuine hard.

Hint

Dummy head. For each group, first check k nodes exist. Reverse exactly k, then reconnect the group's new head to the previous group's tail and recurse/iterate on the rest.

Solution (Java) 
public ListNode reverseKGroup(ListNode head, int k) {
    ListNode dummy = new ListNode(0); dummy.next = head;
    ListNode groupPrev = dummy;
    while (true) {
        ListNode kth = groupPrev;
        for (int i = 0; i < k && kth != null; i++) kth = kth.next;
        if (kth == null) break;                  // fewer than k remain
        ListNode groupNext = kth.next, prev = groupNext, cur = groupPrev.next;
        while (cur != groupNext) {               // reverse this group
            ListNode n = cur.next; cur.next = prev; prev = cur; cur = n;
        }
        ListNode newTail = groupPrev.next;       // old head = new tail
        groupPrev.next = kth;                    // wire previous group → new head
        groupPrev = newTail;
    }
    return dummy.next;
}

Time O(n) · Space O(1). Insight: seeding prev = groupNext auto-connects the reversed group to the rest. Tracking groupPrev/newTail across groups is the bookkeeping that trips people up — draw it.

Drill 4 — hashing meets lists LeetCode 138 · Copy List with Random Pointer

Deep-copy a list where each node also has a random pointer to any node (or null).

Hint

A map from original→copy resolves the random pointers cleanly: first pass creates copies and maps them, second pass wires next/random via the map. (An O(1)-space interleaving trick exists too — mention it.)

Solution (Java) 
public Node copyRandomList(Node head) {
    Map<Node,Node> map = new HashMap<>();
    for (Node c = head; c != null; c = c.next) map.put(c, new Node(c.val));
    for (Node c = head; c != null; c = c.next) {
        map.get(c).next   = map.get(c.next);     // null maps to null
        map.get(c).random = map.get(c.random);
    }
    return map.get(head);
}

Time O(n) · Space O(n). Insight: the map turns "pointer to arbitrary node" into a lookup — this is hashing and lists combined. Note you can drop to O(1) space by interleaving copies between originals, then splitting.
