Lesson 0033 · Interleaving

Mixed Retrieval — DP + Graphs + Backtracking + Heaps + Trees + Lists + Stacks + Search + Windows + Pointers + Hashing

Eleven tools. The new axis: optimise/count with overlapping subproblems (DP) vs enumerate (backtracking) vs locally-greedy.

Do this after a 2–3 day gap from Lessons 0031–0032. The hardest discriminations in interviews live right here: DP vs backtracking (count/optimise vs list-all), DP vs greedy (does a local choice ever need undoing?), and DP vs plain recursion (do subproblems repeat?).

Debrief

The three DP traps. DP vs backtracking: "how many / best" with repeated subproblems is DP at polynomial cost; "list them all" is backtracking at exponential cost. DP vs greedy: if a locally optimal choice can ever be wrong globally, you need DP; if it's provably always safe (interval scheduling, say), greedy is simpler and faster. DP vs recursion: no overlapping subproblems means caching buys nothing — it's just divide-and-conquer. Naming which and why is the Staff differentiator.
