Lesson 0030 · Interleaving

Mixed Retrieval — Graphs + Backtracking + Heaps + Trees + Lists + Stacks + Search + Windows + Pointers + Hashing

Ten tools. The new axis: is there a hidden graph — and if so, which traversal does the question want?

Do this after a 2–3 day gap from Lessons 0028–0029. The skill is two-stage: first spot the graph (nodes? edges?), then pick the traversal — BFS for unweighted shortest, Dijkstra for weighted, topo sort for dependencies, union-find for dynamic grouping, DFS for reachability/components.

The decision fork to internalise

SignalReach for

Drill — name the tool, cold

State the approach and its complexity in under 30 seconds, then check.

Debrief

The graph trap is failing to see the graph — once nodes and edges are named, tool choice is mechanical. The second trap is BFS-vs-Dijkstra: plain BFS only gives shortest paths when every edge has equal weight; add weights and you need the heap. The third is reaching for DFS flood-fill when connectivity is dynamic (edges arriving) — that's union-find's job. Naming the reduction and the right traversal, with complexity, is the Staff signal.
