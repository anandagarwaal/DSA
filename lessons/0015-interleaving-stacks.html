Lesson 0015 · Interleaving

Mixed Retrieval — Stacks + Binary Search + Windows + Pointers + Hashing

Five tools. The new discriminator: "most-recent-unresolved-item" → stack, vs everything else.

Do this after a 2–3 day gap from Lessons 0013–0014. The failure mode now is missing the LIFO/monotonic signal — brute-forcing "next greater" at O(n²) when a stack gives O(n). Train the cold recognition across all five patterns.

The decision fork to internalise

SignalReach for
Next/previous greater or smaller; nested matchingStack (monotonic / plain)
"Min/max value such that feasible"; sorted lookupBinary search
Longest/shortest contiguous run with a constraintSliding window
Sorted, pair/triplet, O(1) spaceConverging two pointers
Contiguous sum with negativesPrefix sum + hash map
"Seen it?" / counts / group-byHash set / map

Drill — name the tool, cold

State the approach and its complexity in under 30 seconds, then check.

Debrief

The stack tell is temporal: "the thing I must act on is the most recently seen one still unresolved." Next-greater, span, nesting, and histogram all share it. If you catch yourself writing a nested loop to look rightward for a bigger element, that's the cue to reach for a monotonic stack and drop O(n²) to O(n).
