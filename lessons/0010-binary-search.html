Lesson 0010 · Binary Search

Binary Search & Search on the Answer

The skill isn't the textbook search — it's recognising a hidden monotonic predicate and bisecting it.

Everyone knows binary search on a sorted array. The L6/L7 differentiator is spotting that a problem hides a monotonic yes/no predicate — false false false true true true — and bisecting to find the boundary. That reframing turns many "hard" problems into O(log) drivers over an O(n) check.

The one invariant that prevents every off-by-one: decide what your search space means and keep it consistent. I teach the "find leftmost true" template — half-open [lo, hi), loop while lo < hi, never mid ± 1 on the side you keep. It generalises to lower/upper bound and to answer-space search.

The one template to memorise

// Smallest x in [lo, hi) with predicate(x) == true.
// Predicate must be monotonic: F...F T...T. Returns hi if none.
int lo = 0, hi = n;                 // half-open
while (lo < hi) {
    int mid = lo + (hi - lo) / 2;   // avoids overflow
    if (predicate(mid)) hi = mid;   // answer is mid or left → keep mid
    else                lo = mid + 1;
}
return lo;                          // == hi, the boundary

Everything else is choosing the predicate. x ≥ target → lower bound. x > target → upper bound. canFinish(capacity) → answer-space search.

Pattern signals. sorted input; "find the minimum/maximum value such that …"; "smallest capacity / speed / days to …"; a feasibility check that gets easier as the parameter grows (or harder as it shrinks). Answer range is numeric and bounded → bisect the answer.

Check your model first

Drill — three problems

Drill 1 — the template, raw LeetCode 704 · Binary Search

Return the index of target in a sorted array, or −1.

Hint

Use lower-bound (smallest index with a[i] ≥ target); then check whether that index actually holds target.

Solution (Java) 
public int search(int[] a, int target) {
    int lo = 0, hi = a.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] >= target) hi = mid;
        else                  lo = mid + 1;
    }
    return (lo < a.length && a[lo] == target) ? lo : -1;
}

Time O(log n) · Space O(1). Insight: deriving plain search from lower-bound means you maintain one template, not three — fewer bugs under interview pressure.

Drill 2 — rotated array LeetCode 33 · Search in Rotated Sorted Array

A sorted array rotated at an unknown pivot; find target's index or −1, in O(log n).

Hint

At each step one half is sorted. Check which (compare a[lo] to a[mid]); if target lies inside that sorted half's range, recurse there, else the other half.

Solution (Java) 
public int search(int[] a, int target) {
    int lo = 0, hi = a.length - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == target) return mid;
        if (a[lo] <= a[mid]) {                         // left half sorted
            if (a[lo] <= target && target < a[mid]) hi = mid - 1;
            else lo = mid + 1;
        } else {                                       // right half sorted
            if (a[mid] < target && target <= a[hi]) lo = mid + 1;
            else hi = mid - 1;
        }
    }
    return -1;
}

Time O(log n) · Space O(1). Insight: "exactly one half is always sorted" is the invariant to state out loud — it's what makes the rotation tractable.

Drill 3 — search on the answer LeetCode 875 · Koko Eating Bananas

Piles of bananas, h hours. Find the minimum integer eating speed k so Koko finishes within h hours.

Hint

The answer is a speed in [1, max(piles)]. hoursNeeded(k) is monotonically non-increasing in k, so "finishes in time" is a F…F T…T predicate. Bisect for the leftmost k that works.

Solution (Java) 
public int minEatingSpeed(int[] piles, int h) {
    int lo = 1, hi = 0;
    for (int p : piles) hi = Math.max(hi, p);
    while (lo < hi) {
        int k = lo + (hi - lo) / 2;
        if (canFinish(piles, k, h)) hi = k;   // feasible → try slower
        else                        lo = k + 1;
    }
    return lo;
}
private boolean canFinish(int[] piles, int k, int h) {
    long hours = 0;
    for (int p : piles) hours += (p + k - 1) / k;   // ceil(p/k)
    return hours <= h;
}

Time O(n log maxPile) · Space O(1). Insight: this is the template applied to a conceptual array of speeds. Recognising the monotone predicate is the entire move — naming it earns the Staff signal.
