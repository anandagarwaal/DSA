Lesson 0020 · Trees — Reps

More Tree Problems

Four reps: BST validation with bounds, lowest common ancestor, reconstruction, and serialize/deserialize.

From Lesson 0019 you have the four skeletons. These reps add top-down bound passing, the LCA recursion, and building trees from traversals. Name the traversal and the per-node job before coding — keep the templates reference handy.

Drill 1 — top-down bounds LeetCode 98 · Validate Binary Search Tree

Decide whether a binary tree is a valid BST.

Hint

Pass an allowed (low, high) range down. Each node must lie strictly inside; recurse left with high = node.val, right with low = node.val. Use long sentinels to dodge Integer.MIN/MAX edge cases.

Solution (Java) 
public boolean isValidBST(TreeNode root) {
    return valid(root, Long.MIN_VALUE, Long.MAX_VALUE);
}
private boolean valid(TreeNode n, long low, long high) {
    if (n == null) return true;
    if (n.val <= low || n.val >= high) return false;
    return valid(n.left, low, n.val) && valid(n.right, n.val, high);
}

Time O(n) · Space O(h). Insight: a node only needs to beat its ancestor bounds, not just its parent — passing the range down is what catches violations several levels apart. The classic wrong answer only compares parent-child.

Drill 2 — LCA recursion LeetCode 236 · Lowest Common Ancestor

Find the lowest common ancestor of two nodes in a binary tree.

Hint

Postorder. If a subtree contains p or q, return it upward. A node that receives non-null from both sides is the LCA; otherwise propagate the non-null side.

Solution (Java) 
public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    if (root == null || root == p || root == q) return root;
    TreeNode l = lowestCommonAncestor(root.left, p, q);
    TreeNode r = lowestCommonAncestor(root.right, p, q);
    if (l != null && r != null) return root;   // p and q split here → LCA
    return (l != null) ? l : r;                // both on one side, or neither
}

Time O(n) · Space O(h). Insight: "found-something" bubbles up; the first node seeing both sides report a find is the split point. Explaining why that's the LCA is the interview point.

Drill 3 — reconstruct LeetCode 105 · Build Tree from Preorder & Inorder

Rebuild a binary tree from its preorder and inorder traversals.

Hint

Preorder's first element is the root. Find it in inorder: everything left is the left subtree, right is the right subtree. Recurse, using a hashmap of value→inorder-index for O(1) splits and a moving preorder pointer.

Solution (Java) 
private int pre = 0;
private Map<Integer,Integer> idx = new HashMap<>();
public TreeNode buildTree(int[] preorder, int[] inorder) {
    for (int i = 0; i < inorder.length; i++) idx.put(inorder[i], i);
    return build(preorder, 0, inorder.length - 1);
}
private TreeNode build(int[] preorder, int lo, int hi) {
    if (lo > hi) return null;
    int rootVal = preorder[pre++];
    TreeNode root = new TreeNode(rootVal);
    int mid = idx.get(rootVal);
    root.left  = build(preorder, lo, mid - 1);    // must build left before right
    root.right = build(preorder, mid + 1, hi);
    return root;
}

Time O(n) · Space O(n). Insight: the global pre pointer must advance left-subtree-first to match preorder's order — swap the two recursive calls and it breaks.

Drill 4 — serialize LeetCode 297 · Serialize and Deserialize Binary Tree

Encode a tree to a string and decode it back. A design hard.

Hint

Preorder with explicit null markers. Serialize: root, then left, then right, writing "#" for null. Deserialize: consume tokens in the same order, building recursively.

Solution (Java) 
public String serialize(TreeNode root) {
    StringBuilder sb = new StringBuilder();
    ser(root, sb);
    return sb.toString();
}
private void ser(TreeNode n, StringBuilder sb) {
    if (n == null) { sb.append("#,"); return; }
    sb.append(n.val).append(',');
    ser(n.left, sb); ser(n.right, sb);
}
public TreeNode deserialize(String data) {
    return des(new ArrayDeque<>(Arrays.asList(data.split(","))));
}
private TreeNode des(Deque<String> q) {
    String t = q.poll();
    if (t.equals("#")) return null;
    TreeNode n = new TreeNode(Integer.parseInt(t));
    n.left = des(q); n.right = des(q);
    return n;
}

Time O(n) · Space O(n). Insight: null markers make preorder uniquely decodable — without them, structure is ambiguous. Encoding/decoding in the same traversal order is what makes it reversible.
