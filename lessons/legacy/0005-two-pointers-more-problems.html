Lesson 0005 · Two Pointers — Reps

More Two-Pointer Problems

Four reps spanning fast/slow, three-way partition, and the famous "hard" that's really two pointers in disguise.

From Lesson 0004 you have the two families: converging (opposite ends) and fast/slow (same direction). These reps stretch the fast/slow family into in-place rewriting and add a three-pointer variant. Name the family aloud before coding, and state the complexity first.

Drill 1 — fast/slow write pointer LeetCode 283 · Move Zeroes

Move all zeroes in int[] nums to the end, in place, preserving the order of non-zero elements.

Hint

slow marks where the next non-zero goes. Walk fast; on each non-zero, write it to slow and advance. Then fill the rest with zeroes (or swap as you go).

Solution (Java) 
public void moveZeroes(int[] nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.length; fast++) {
        if (nums[fast] != 0) {
            int t = nums[slow]; nums[slow] = nums[fast]; nums[fast] = t; // swap
            slow++;
        }
    }
}

Time O(n) · Space O(1). Insight: swapping (not just overwriting) keeps it a single pass and leaves zeroes trailing automatically.

Drill 2 — dedup in place LeetCode 26 · Remove Duplicates from Sorted Array

Sorted int[] nums; remove duplicates in place and return the new length k; the first k slots must hold the unique values.

Hint

slow points at the last unique written. When nums[fast] differs from nums[slow], advance slow and copy. Sortedness means equal values are adjacent.

Solution (Java) 
public int removeDuplicates(int[] nums) {
    if (nums.length == 0) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.length; fast++) {
        if (nums[fast] != nums[slow]) {
            nums[++slow] = nums[fast];
        }
    }
    return slow + 1;
}

Time O(n) · Space O(1). Insight: the "lagging write pointer" is the canonical in-place compaction template — you'll reuse it constantly.

Drill 3 — three-way partition LeetCode 75 · Sort Colors

Sort an array of 0s, 1s, and 2s in place, one pass, O(1) space (the Dutch National Flag problem).

Hint

Three pointers: lo (next 0 slot), hi (next 2 slot), mid (scanner). If nums[mid]==0 swap with lo and advance both; if ==2 swap with hi and shrink hi (don't advance mid — the swapped-in value is unexamined); if ==1 just advance mid.

Solution (Java) 
public void sortColors(int[] nums) {
    int lo = 0, mid = 0, hi = nums.length - 1;
    while (mid <= hi) {
        if (nums[mid] == 0)      { swap(nums, lo++, mid++); }
        else if (nums[mid] == 2) { swap(nums, mid, hi--); }   // don't advance mid
        else                     { mid++; }
    }
}
private void swap(int[] a, int i, int j) { int t=a[i]; a[i]=a[j]; a[j]=t; }

Time O(n) · Space O(1). Insight: not advancing mid after a hi-swap is the classic bug — the incoming value still needs classifying.

Drill 4 — the "hard" LeetCode 42 · Trapping Rain Water

Given bar heights, compute the water trapped after raining. A Google/Meta favourite.

Hint

Water above bar i = min(maxLeft, maxRight) − h[i]. Two pointers from both ends, tracking leftMax/rightMax: the side with the smaller running max is the bottleneck, so process and advance it. O(1) space, no precomputed arrays.

Solution (Java) 
public int trap(int[] h) {
    int lo = 0, hi = h.length - 1, leftMax = 0, rightMax = 0, water = 0;
    while (lo < hi) {
        if (h[lo] < h[hi]) {
            leftMax = Math.max(leftMax, h[lo]);
            water += leftMax - h[lo];
            lo++;
        } else {
            rightMax = Math.max(rightMax, h[hi]);
            water += rightMax - h[hi];
            hi--;
        }
    }
    return water;
}

Time O(n) · Space O(1). Insight: when h[lo] < h[hi], the left side is guaranteed bounded by some taller bar on the right, so leftMax alone settles the water there. Being able to prove that is the interview win.
