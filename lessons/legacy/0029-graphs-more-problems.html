Lesson 0029 · Graphs — Reps

More Graph Problems

Four reps: multi-source BFS, clone via hashmap, topo order output, and Dijkstra for weighted shortest paths.

From Lesson 0028 you have BFS, DFS, Kahn's topo sort, and union-find. These reps add three high-value variations: multi-source BFS (seed the queue with many starts), graph cloning (old→new hashmap), and Dijkstra (a heap-ordered BFS for weighted edges) — where the heap module meets the graph module.

Drill 1 — multi-source BFS LeetCode 994 · Rotting Oranges

Each minute, rotten oranges rot 4-adjacent fresh ones. Return minutes until none are fresh (or -1).

Hint

Seed the BFS queue with all rotten cells at once (time 0). Each BFS level is one minute. Track remaining fresh count; if any remain when the queue empties, return -1.

Solution (Java) 
public int orangesRotting(int[][] g) {
    Queue<int[]> q = new LinkedList<>();
    int fresh = 0, m = g.length, n = g[0].length;
    for (int r = 0; r < m; r++) for (int c = 0; c < n; c++) {
        if (g[r][c] == 2) q.offer(new int[]{r, c});
        else if (g[r][c] == 1) fresh++;
    }
    int[][] D = {{1,0},{-1,0},{0,1},{0,-1}};
    int mins = 0;
    while (!q.isEmpty() && fresh > 0) {
        mins++;
        for (int i = q.size(); i > 0; i--) {
            int[] cell = q.poll();
            for (int[] d : D) {
                int r = cell[0]+d[0], c = cell[1]+d[1];
                if (r>=0 && c>=0 && r<m && c<n && g[r][c]==1) {
                    g[r][c] = 2; fresh--; q.offer(new int[]{r, c});
                }
            }
        }
    }
    return fresh == 0 ? mins : -1;
}

Time O(m·n) · Space O(m·n). Insight: seeding the queue with every source makes the BFS frontier expand from all rot points simultaneously — the level count is the answer, no per-source reruns.

Drill 2 — clone with a map LeetCode 133 · Clone Graph

Deep-copy a connected undirected graph given a node reference.

Hint

DFS (or BFS) with a hashmap from original node → its clone. The map both stores results and serves as the visited set, breaking cycles.

Solution (Java) 
private Map<Node, Node> seen = new HashMap<>();
public Node cloneGraph(Node node) {
    if (node == null) return null;
    if (seen.containsKey(node)) return seen.get(node);   // already cloned → break cycle
    Node copy = new Node(node.val);
    seen.put(node, copy);                                // record BEFORE recursing
    for (Node nb : node.neighbors) copy.neighbors.add(cloneGraph(nb));
    return copy;
}

Time O(V+E) · Space O(V). Insight: putting the clone in the map before recursing into neighbours is what stops infinite recursion on cycles — the same hashmap is visited-set and output in one.

Drill 3 — emit the order LeetCode 210 · Course Schedule II

Return a valid order to take all courses, or an empty array if impossible.

Hint

Same Kahn's BFS as Course Schedule, but append each popped node to an output list. If the list reaches n entries, it's a valid topological order; otherwise return empty.

Solution (Java) 
public int[] findOrder(int n, int[][] prereqs) {
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());
    int[] indeg = new int[n];
    for (int[] p : prereqs) { adj.get(p[1]).add(p[0]); indeg[p[0]]++; }
    Queue<Integer> q = new LinkedList<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);
    int[] order = new int[n]; int k = 0;
    while (!q.isEmpty()) {
        int u = q.poll(); order[k++] = u;
        for (int v : adj.get(u)) if (--indeg[v] == 0) q.offer(v);
    }
    return k == n ? order : new int[0];        // incomplete ⇒ cycle ⇒ no order
}

Time O(V+E) · Space O(V+E). Insight: topo sort and cycle detection are the same algorithm — the order falls out of the process, and a short order signals a cycle.

Drill 4 — weighted shortest path LeetCode 743 · Network Delay Time

Time for a signal from node k to reach all n nodes across weighted edges.

Hint

Dijkstra: a min-heap ordered by distance-so-far. Pop the closest unsettled node, relax its edges. The answer is the max finalized distance (or -1 if any node is unreachable).

Solution (Java) 
public int networkDelayTime(int[][] times, int n, int k) {
    Map<Integer, List<int[]>> adj = new HashMap<>();
    for (int[] t : times) adj.computeIfAbsent(t[0], x -> new ArrayList<>())
                              .add(new int[]{t[1], t[2]});
    int[] dist = new int[n + 1]; Arrays.fill(dist, Integer.MAX_VALUE); dist[k] = 0;
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[1] - b[1]);
    pq.offer(new int[]{k, 0});
    while (!pq.isEmpty()) {
        int[] cur = pq.poll(); int u = cur[0], d = cur[1];
        if (d > dist[u]) continue;            // stale heap entry, skip
        for (int[] e : adj.getOrDefault(u, List.of())) {
            int nd = d + e[1];
            if (nd < dist[e[0]]) { dist[e[0]] = nd; pq.offer(new int[]{e[0], nd}); }
        }
    }
    int ans = 0;
    for (int i = 1; i <= n; i++) ans = Math.max(ans, dist[i]);
    return ans == Integer.MAX_VALUE ? -1 : ans;
}

Time O(E log V) · Space O(V+E). Insight: Dijkstra is BFS with a min-heap instead of a plain queue — the heap always settles the globally-closest node next, which is why it needs non-negative weights. The "stale entry" skip avoids a decrease-key.

Self-check

Classify each: multi-source BFS (D1), clone-via-map (D2), Kahn's order (D3), Dijkstra (D4). The two transferable ideas: seed BFS with many sources for "simultaneous spread," and Dijkstra = heap-ordered BFS for weighted graphs — that's where this module fuses with heaps.
