Lesson 0009 · Interleaving

Mixed Retrieval — Sliding Window + Two Pointers + Hashing

Three patterns now overlap on contiguous-array problems. The skill is the cold first read.

Do this after a 2–3 day gap from Lessons 0007–0008. All three tools touch arrays and substrings; the trap is grabbing a window when the data isn't contiguous, or isn't monotonic. Train the discrimination, not the mechanics.

The decision fork to internalise

SignalReach for
Longest/shortest CONTIGUOUS run, positive/count constraintSliding window
Contiguous sum with NEGATIVESPrefix sum + hash map
Sorted array, pair/triplet, O(1) spaceConverging two pointers
"Seen it?" / counts / group-by, order irrelevantHash set / map
In-place compaction / partitionFast/slow pointers
Permutation/anagram of a fixed string inside anotherFixed-size count window

Drill — name the tool, cold

State the approach and its complexity in under 30 seconds, then check.

Debrief

The sharpest distinction here: contiguous + monotonic → window; contiguous + negatives → prefix-sum + map; not contiguous → sort/hash. If an interviewer slips a negative number into a "longest subarray sum" problem, naming why the window breaks is the Staff-level signal.
