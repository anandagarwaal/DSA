Lesson 0007 · Sliding Window

The Sliding Window Pattern

Two same-direction pointers plus a running aggregate — turns "best contiguous subarray/substring" from O(n²) into O(n).

A window is just two pointers moving the same way, with a summary of what's between them (a sum, a count map, a distinct-count). Instead of recomputing each candidate subarray from scratch, you add the element entering on the right and remove the one leaving on the left — amortised O(1) per step.

Crucial precondition: the window only works when extending it changes the aggregate monotonically (e.g. all-positive sums, character counts). With negatives, a longer window can shrink the sum — so subarray-sum-with-negatives is a prefix-sum + hash problem, not a window. Stating that boundary is a senior tell.

The two shapes

Fixed-size window

int sum = 0, best = Integer.MIN_VALUE;
for (int r = 0; r < n; r++) {
    sum += a[r];
    if (r >= k - 1) {           // window now spans exactly k
        best = Math.max(best, sum);
        sum -= a[r - k + 1];    // evict the left edge
    }
}

Variable-size window (expand, then shrink while invalid)

int left = 0;
for (int right = 0; right < n; right++) {
    add(a[right]);                       // grow window to include right
    while (windowInvalid()) {            // restore the constraint
        remove(a[left]);
        left++;
    }
    best = Math.max(best, right - left + 1);
}

The variable form is the workhorse: grow greedily, shrink only when a constraint breaks. Each index enters and leaves at most once → O(n).

Pattern signals. "longest / shortest / maximum contiguous subarray or substring such that …", "at most K distinct", "window of size k", "no repeating characters". Keyword: contiguous. Not contiguous, or has negatives breaking monotonicity → reach for a different tool.

Check your model first

Drill — three problems

Drill 1 — fixed window LeetCode 643 · Maximum Average Subarray I

Find the contiguous subarray of length k with the maximum average; return that average.

Hint

Maximising the average over a fixed length = maximising the sum. Maintain a running sum; once the window reaches size k, record it and evict the left edge.

Solution (Java) 
public double findMaxAverage(int[] nums, int k) {
    double sum = 0, best;
    for (int i = 0; i < k; i++) sum += nums[i];
    best = sum;
    for (int r = k; r < nums.length; r++) {
        sum += nums[r] - nums[r - k];   // slide: add right, drop left
        best = Math.max(best, sum);
    }
    return best / k;
}

Time O(n) · Space O(1). Insight: the single += a[r] − a[r−k] is the whole pattern — never recompute the window from scratch.

Drill 2 — variable window + map LeetCode 3 · Longest Substring Without Repeating Characters

Return the length of the longest substring of s with all distinct characters.

Hint

Track the last index of each character. When the incoming char was seen inside the current window, jump left to just past its previous position. Window size is right − left + 1.

Solution (Java) 
public int lengthOfLongestSubstring(String s) {
    Map<Character,Integer> last = new HashMap<>();
    int left = 0, best = 0;
    for (int right = 0; right < s.length(); right++) {
        char c = s.charAt(right);
        if (last.containsKey(c) && last.get(c) >= left) {
            left = last.get(c) + 1;          // skip past the duplicate
        }
        last.put(c, right);
        best = Math.max(best, right - left + 1);
    }
    return best;
}

Time O(n) · Space O(min(n, charset)). Insight: the >= left guard matters — a duplicate that fell out of the window left is irrelevant. Note how hashing and the window combine here.

Drill 3 — shrink to satisfy LeetCode 209 · Minimum Size Subarray Sum

Given positive int[] nums and target, return the minimal length of a contiguous subarray whose sum ≥ target (0 if none).

Hint

Grow right, adding to sum. While sum ≥ target, record the length and shrink from left. Positivity guarantees shrinking only decreases the sum — that's why it's a window.

Solution (Java) 
public int minSubArrayLen(int target, int[] nums) {
    int left = 0, sum = 0, best = Integer.MAX_VALUE;
    for (int right = 0; right < nums.length; right++) {
        sum += nums[right];
        while (sum >= target) {
            best = Math.min(best, right - left + 1);
            sum -= nums[left++];
        }
    }
    return best == Integer.MAX_VALUE ? 0 : best;
}

Time O(n) · Space O(1). Insight: it's "shrink while valid" (minimising) vs Drill 2's "shrink while invalid" (maximising) — know both directions.
