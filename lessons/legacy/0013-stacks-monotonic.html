Lesson 0013 · Stacks & Monotonic Stack

Stacks & the Monotonic Stack

A stack tracks "the most recent unresolved thing." Keep it monotonic and "next greater/smaller" collapses to O(n).

The plain stack handles nesting and matching — parentheses, undo, expression evaluation. The power-up is the monotonic stack: you keep the stack sorted (increasing or decreasing) by popping anything that violates the order as each element arrives. Each pop resolves a pending question like "what's the next greater element to your right?"

Why O(n) despite the inner while-loop: each index is pushed once and popped at most once, so total pops ≤ n. That amortised argument — "n pushes, n pops" — is the thing to say aloud; it's the same shape as the sliding-window linearity proof.

The monotonic-stack template

// Next greater element to the right, for each index.
int[] res = new int[n];
Arrays.fill(res, -1);
Deque<Integer> stack = new ArrayDeque<>();   // holds INDICES, values decreasing
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && a[i] > a[stack.peek()]) {
        res[stack.pop()] = a[i];   // a[i] is the next greater for the popped index
    }
    stack.push(i);
}
// indices left on the stack have no greater element → stay -1

Flip the comparison for next-smaller; iterate right-to-left for "previous" variants. Store indices (not values) so you can also compute distances/widths.

Pattern signals. "next/previous greater or smaller element", "how many days until warmer", "largest rectangle", "valid parentheses", "evaluate/parse nested structure", anything where the most recent unresolved item is the one you act on first (LIFO).

Check your model first

Drill — three problems

Drill 1 — plain stack, matching LeetCode 20 · Valid Parentheses

Given a string of ()[]{}, decide if every bracket is correctly closed and nested.

Hint

Push opening brackets. On a closer, the top must be its matching opener — else invalid. The stack must be empty at the end.

Solution (Java) 
public boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    Map<Character,Character> close = Map.of(')','(', ']','[', '}','{');
    for (char c : s.toCharArray()) {
        if (close.containsKey(c)) {
            if (st.isEmpty() || st.pop() != close.get(c)) return false;
        } else {
            st.push(c);
        }
    }
    return st.isEmpty();
}

Time O(n) · Space O(n). Insight: mapping closer→opener lets one branch handle all three bracket types — cleaner than three nested conditions.

Drill 2 — monotonic stack LeetCode 739 · Daily Temperatures

For each day, how many days until a warmer temperature? 0 if none.

Hint

Decreasing monotonic stack of indices. When today is warmer than the day at the top, pop it — today is its answer, and the distance is i − poppedIndex.

Solution (Java) 
public int[] dailyTemperatures(int[] t) {
    int n = t.length;
    int[] res = new int[n];
    Deque<Integer> st = new ArrayDeque<>();   // indices, temps decreasing
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && t[i] > t[st.peek()]) {
            int j = st.pop();
            res[j] = i - j;
        }
        st.push(i);
    }
    return res;
}

Time O(n) · Space O(n). Insight: storing indices (not temps) is what lets you recover the distance — a recurring reason to push indices.

Drill 3 — the "hard" LeetCode 84 · Largest Rectangle in Histogram

Given bar heights, find the area of the largest axis-aligned rectangle.

Hint

Increasing monotonic stack of indices. When a shorter bar arrives, pop taller bars; each popped bar's rectangle extends from the new bar's left back to the element below it on the stack. Use a sentinel of height 0 at the end to flush.

Solution (Java) 
public int largestRectangleArea(int[] h) {
    Deque<Integer> st = new ArrayDeque<>();   // indices, heights increasing
    int best = 0, n = h.length;
    for (int i = 0; i <= n; i++) {
        int cur = (i == n) ? 0 : h[i];        // sentinel flushes the stack
        while (!st.isEmpty() && cur < h[st.peek()]) {
            int height = h[st.pop()];
            int leftBound = st.isEmpty() ? -1 : st.peek();
            int width = i - leftBound - 1;
            best = Math.max(best, height * width);
        }
        st.push(i);
    }
    return best;
}

Time O(n) · Space O(n). Insight: when you pop bar j, its width spans from the current index back to the new stack top — both bounds are the first shorter bars on each side. Articulating that width formula is the interview crux.
