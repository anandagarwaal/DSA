Lesson 0019 · Trees

Trees — BFS, DFS & Recursion Templates

Almost every tree problem is one of four skeletons. Pick the traversal, then vary only the per-node work.

Trees reward template fluency. The decisions are: BFS or DFS? and if DFS, pre/in/post-order? Get those right and the rest is local per-node logic. Keep the traversal templates reference open while you drill — this lesson teaches when to reach for each.

The single most useful instinct: "compute a property" → postorder. Recurse to children, combine their returns into your answer, and stash the global best in a field. Height, diameter, balanced-check, max-path-sum, valid-BST all fit this mould — learning it once unlocks a dozen problems.

Drill — three problems

Drill 1 — postorder aggregate LeetCode 104 · Maximum Depth of Binary Tree

Return the maximum depth (root to deepest leaf).

Hint

Postorder: depth = 1 + max(left depth, right depth). Null is depth 0.

Solution (Java) 
public int maxDepth(TreeNode root) {
    if (root == null) return 0;
    return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
}

Time O(n) · Space O(h). Insight: this 3-line postorder is the template; every "compute a property" tree problem is a variation on combining children's returns.

Drill 2 — BFS level order LeetCode 102 · Binary Tree Level Order Traversal

Return node values grouped by level, top to bottom.

Hint

Queue-based BFS. At each level snapshot q.size() and process exactly that many nodes, collecting them into one level list before moving on.

Solution (Java) 
public List<List<Integer>> levelOrder(TreeNode root) {
    List<List<Integer>> res = new ArrayList<>();
    if (root == null) return res;
    Queue<TreeNode> q = new LinkedList<>(); q.offer(root);
    while (!q.isEmpty()) {
        int n = q.size();
        List<Integer> level = new ArrayList<>();
        for (int i = 0; i < n; i++) {
            TreeNode c = q.poll();
            level.add(c.val);
            if (c.left  != null) q.offer(c.left);
            if (c.right != null) q.offer(c.right);
        }
        res.add(level);
    }
    return res;
}

Time O(n) · Space O(width). Insight: the int n = q.size() freeze is the entire trick for separating levels — without it, levels bleed together.

Drill 3 — postorder with a global LeetCode 124 · Binary Tree Maximum Path Sum

Find the maximum path sum, where a path is any node-to-node route. A hard.

Hint

For each node, the best downward contribution is val + max(0, left, right one-sided). But the best path through the node may use both children — update a global max with val + leftGain + rightGain while returning only the one-sided gain.

Solution (Java) 
private int best = Integer.MIN_VALUE;
public int maxPathSum(TreeNode root) { gain(root); return best; }
private int gain(TreeNode node) {
    if (node == null) return 0;
    int l = Math.max(0, gain(node.left));    // clamp negatives to 0
    int r = Math.max(0, gain(node.right));
    best = Math.max(best, node.val + l + r); // path through node (both sides)
    return node.val + Math.max(l, r);        // can only extend one side upward
}

Time O(n) · Space O(h). Insight: the split between what you return (one side, to extend a parent path) and what you record (both sides, a complete path) is the crux — articulating it is the interview win.
