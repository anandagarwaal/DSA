Lesson 0018 · Interleaving

Mixed Retrieval — Linked Lists + Stacks + Binary Search + Windows + Pointers + Hashing

Six tools. The new axis: pointer surgery on nodes vs index-based work on arrays.

Do this after a 2–3 day gap from Lessons 0016–0017. The list idioms (reversal, fast/slow, dummy head) echo array two-pointers — the discriminator is the data structure, not the move. Train spotting which idiom a node-based problem needs.

The decision fork to internalise

SignalReach for
Node list: middle, cycle, nth-from-end, reorderFast/slow + dummy + reversal
Next/previous greater; nested matchingStack (monotonic / plain)
"Min/max value such that feasible"; sorted lookupBinary search
Longest/shortest contiguous run with a constraintSliding window
Sorted array, pair/triplet, O(1) spaceConverging two pointers
"Seen it?" / arbitrary-node lookup / group-byHash set / map

Drill — name the tool, cold

State the approach and its complexity in under 30 seconds, then check.

Debrief

The list reflex: with O(1) space required on a node structure, you're almost always composing fast/slow, reversal, and a dummy head — not copying into an array. And when arbitrary-node lookup appears (random pointers, intersection), a hash map bridges lists and hashing. Naming the composition up front is the Staff move.
