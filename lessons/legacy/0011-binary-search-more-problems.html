Lesson 0011 · Binary Search — Reps

More Binary Search Problems

Four reps: boundary-finding, a 2D twist, a no-sorted-input minimum, and another answer-space search.

From Lesson 0010 you have the leftmost-true template and the answer-space reframing. These reps stretch both. Before coding each: state your search space and the predicate's F→T direction aloud — that single sentence prevents the off-by-ones.

Drill 1 — find the boundaries LeetCode 34 · First and Last Position

In a sorted array with duplicates, return the first and last index of target (or [-1,-1]).

Hint

First index = lower bound (a[i] ≥ target). Last index = upper bound (a[i] > target) minus one. One template, two predicates.

Solution (Java) 
public int[] searchRange(int[] a, int target) {
    int lo = lowerBound(a, target), hi = lowerBound(a, target + 1) - 1;
    if (lo < a.length && a[lo] == target) return new int[]{lo, hi};
    return new int[]{-1, -1};
}
private int lowerBound(int[] a, int t) {       // smallest i with a[i] >= t
    int lo = 0, hi = a.length;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] >= t) hi = mid; else lo = mid + 1;
    }
    return lo;
}

Time O(log n) · Space O(1). Insight: upperBound(t) = lowerBound(t+1) — derive one from the other instead of maintaining a second loop.

Drill 2 — bisect a matrix LeetCode 74 · Search a 2D Matrix

Each row sorted, first of each row > last of previous. Decide if target is present in O(log(m·n)).

Hint

Treat the matrix as one flat sorted array of length m*n; map index mid to (mid / cols, mid % cols).

Solution (Java) 
public boolean searchMatrix(int[][] m, int target) {
    int rows = m.length, cols = m[0].length;
    int lo = 0, hi = rows * cols;            // half-open over flattened index
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        int v = m[mid / cols][mid % cols];
        if (v == target) return true;
        if (v < target) lo = mid + 1; else hi = mid;
    }
    return false;
}

Time O(log(mn)) · Space O(1). Insight: the index-flattening trick reuses 1D binary search verbatim — recognising the isomorphism is the win.

Drill 3 — minimum of rotated LeetCode 153 · Find Minimum in Rotated Sorted Array

Find the minimum element of a sorted array rotated at an unknown pivot, in O(log n).

Hint

Compare a[mid] to a[hi]. If a[mid] > a[hi] the minimum is strictly right of mid; else it's mid or left. The predicate is "is mid in the left (higher) segment?"

Solution (Java) 
public int findMin(int[] a) {
    int lo = 0, hi = a.length - 1;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] > a[hi]) lo = mid + 1;   // min is to the right
        else                hi = mid;       // min is mid or left
    }
    return a[lo];
}

Time O(log n) · Space O(1). Insight: compare to a[hi], not a[lo] — comparing to a[lo] mishandles the already-sorted case.

Drill 4 — answer-space, harder LeetCode 1011 · Capacity To Ship Packages Within D Days

Ship weights in order within days. Find the minimum ship capacity.

Hint

Capacity lies in [max(weights), sum(weights)]. daysNeeded(cap) is non-increasing in cap → bisect for the smallest feasible capacity.

Solution (Java) 
public int shipWithinDays(int[] w, int days) {
    int lo = 0, hi = 0;
    for (int x : w) { lo = Math.max(lo, x); hi += x; }   // bounds
    while (lo < hi) {
        int cap = lo + (hi - lo) / 2;
        if (feasible(w, cap, days)) hi = cap; else lo = cap + 1;
    }
    return lo;
}
private boolean feasible(int[] w, int cap, int days) {
    int need = 1, load = 0;
    for (int x : w) {
        if (load + x > cap) { need++; load = 0; }
        load += x;
    }
    return need <= days;
}

Time O(n log sum) · Space O(1). Insight: same shape as Koko — lower bound is max (one item must fit), upper bound is sum (one trip). Getting the bounds right is half the problem.
