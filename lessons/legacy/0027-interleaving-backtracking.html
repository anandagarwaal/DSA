Lesson 0027 · Interleaving

Mixed Retrieval — Backtracking + Heaps + Trees + Lists + Stacks + Search + Windows + Pointers + Hashing

Nine tools. The new axis: enumerate every solution (exponential) vs find/optimise one (polynomial).

Do this after a 2–3 day gap from Lessons 0025–0026. The skill is the cost-of-output test: if the answer is "list all arrangements," brace for backtracking's exponential fan-out; if it's "how many" or "the best one," a polynomial tool (DP, greedy, search) almost always exists instead.

Drill — name the tool, cold

State the approach and its complexity in under 30 seconds, then check.

Debrief

The backtracking trap is using it when you only need a count or an optimum — that's almost always DP or greedy at polynomial cost, not an exponential enumeration. The second trap is missing the prune: sort-then-skip for duplicates, an early infeasibility return, or constraint sets for O(1) validity. When the problem genuinely wants every solution, backtracking is correct and the exponential output is unavoidable — saying that out loud (and bounding it) is the Staff signal.
