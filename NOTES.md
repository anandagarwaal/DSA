# Teaching Notes

## User profile
- Targeting Google + Meta, L6/L7 (Staff-level) SWE.
- Currently at Flipkart. Senior engineer — strong real-world experience, rusty on DSA.
- Language: **Java**.

## Preferences
- **Mix style:** short concept lesson → immediate drill with tight, ideally
  automatic feedback. Don't lecture long; get to retrieval fast.
- Sessions short and self-contained (working full-time).

## Teaching approach
- Pattern-by-pattern curriculum with spaced review and interleaving (3–6 mo runway).
- Every lesson: re-establish complexity reasoning (rusty learner) + the *why*
  (Google bar) + clean idiomatic Java (Meta speed bar).
- Quizzes: keep all answer options equal length (no formatting tells).
- Each lesson ends with: primary source + reminder to ask the teacher follow-ups.
- Shared CSS at `assets/course.css`; every page has a top "Course home" link.
- `index.html` is the course home / navigation hub.

## Per-topic CADENCE (user-requested, repeat for every pattern)
1. **Lesson** — concept + drills (builds the model)
2. **More problems** — extra reps, same pattern (builds fluency)
3. **Interleaving** — blind mixed retrieval across all patterns learned so far,
   done after a 2–3 day gap (builds durable recognition)
Then start the next pattern. Each new interleaving step folds in prior patterns.
