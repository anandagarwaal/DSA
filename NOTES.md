## Method (since 2026-09-19): The Math Academy Way
The operational rules are in `CLAUDE.md`. Summary:
- **Diagnose, don't assume.** All old-course topics start `unverified`, and foundations
  are tested too.
- **Knowledge graph** (`knowledge-graph.json`): foundation topics F01–F16 sit under
  the twelve pattern topics P01–P17. Only frontier topics get taught.
- **Knowledge points**: each topic is taught in small steps, with a quiz after each
  step, then an end-of-topic quiz, then a cumulative end-of-module quiz.
- **Intuition first**: every topic has a `picture` (its geometric/visual model), and
  quizzes must test it along with why/what-breaks/counterexample/transfer questions.
- **Spaced repetition** (`tools/srs.py`, state in `progress.json`): due reviews open
  every session, interleaved, closed-book.

This replaces the old per-topic cadence (lesson → more problems → interleave after a
2–3 day gap). The old cadence was blocked practice plus a single spaced revisit.

## Preferences

- Wants to be pushed: no lazy answers accepted, justifications required.

## The lessons (rebuilt 2026-09-20)
Self-contained HTML, driven by `assets/engine.js` and one content file per topic in
`content/`. Anand can learn without chat: `python3 tools/serve.py`, then
<http://localhost:8000>. 33 topics, 132 steps, 717 questions, 63 Java practice solutions.

- Lesson shells in `lessons/` are generated by `tools/build.py`; edit `content/<ID>.js`, not the HTML.
- The old pattern lessons live in `lessons/legacy/` (0001–0036) as extra drills.
- Validate with `node tools/check_content.js` and `node tools/check_java.js`.

## Lesson content format (for any new topic)
- One step per knowledge point: short explanation, worked example with labelled subgoals,
  the `picture` (inline SVG or ASCII), then ≥ 4 questions (3 to pass, 1 spare), mixed types.
- Question types: `mcq`, `multi`, `num`, `free` (self-graded against a rubric).
- Every topic quiz: ≥ 5 questions including a free-response and a transfer question.
- Keep MCQ options the same length, so formatting gives nothing away (the checker warns).
- Compute every numeric/trace answer with a script before writing it.
